# ArchaeoCAD Mobile

PWA entrypoint for ArchaeoCAD Mobile.

To publish with GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the root folder.

After Pages finishes publishing, use:

https://jj-martinez-garcia.github.io/ArchaeoCAD/

The entrypoint registers a service worker and manifest, then opens the full ArchaeoCAD Mobile application.
